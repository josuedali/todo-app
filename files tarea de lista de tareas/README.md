# Todo App

Lista de tareas hecha con HTML, CSS y JavaScript puro.

## Funciones
- Agregar tareas (con mensaje de error si el campo está vacío)
- Editar (doble clic sobre el texto), eliminar y completar tareas
- Contadores: total, completadas e incompletas
- Tema claro y oscuro (botón ◐; usa el del sistema por defecto)
- Responsiva y sin scroll de página; el texto largo se ajusta sin romper el diseño

## Estructura
- `index.html`: estructura
- `style.css`: estilos y temas
- `script.js`: lógica

## Ver el proyecto
- Demo: https://josuedali.github.io/todo-app/
- Local: abre `index.html` en el navegador
